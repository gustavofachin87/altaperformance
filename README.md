# Oficina Mecânica Alta Performance

Landing page estática da Alta Performance, oficina mecânica em Curitiba/PR.

## Estrutura

```
index.html      página
css/style.css   estilos
js/main.js      animações e configuração (bloco CONFIG no topo)
Logo.png        logo
fotos/1-6.jpg   fotos da galeria
```

## Como editar

Abra `js/main.js` e altere o bloco `CONFIG` (WhatsApp, telefone, endereço, horário, link do mapa e fotos).

## Como ver localmente

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

Repositório > Settings > Pages > Deploy from a branch > `main` / `(root)`.
